PAUSED · CASE STUDY

Knot turned X bookmarks into a searchable second brain.

An AI browser extension that saved bookmarks with zero manual effort and made them instantly searchable. Tested across four channels over two weeks. Paused when retention didn't materialize.

01

What actually shipped

A Chrome MV3 extension — background service worker, content script, and popup — backed by Supabase for auth and storage and Groq's Llama-3.3-70B for categorization, plus a separately hosted web dashboard. The channel test below ran on top of a product that worked end-to-end, not a clickable prototype.

Problem 1

X's bookmark list is virtualized

Only ~4–6 tweets ever exist in the DOM at once — older ones get removed as new ones scroll in. A scraper that counts DOM nodes to detect new content sees the same count forever and gives up immediately. Fixed by accumulating tweet URLs into a persistent map across scroll cycles, stopping only after several consecutive scrolls return zero new URLs. Import went from 0 bookmarks recovered to 93 on the same account.

Problem 2

Auth has to survive a worker that keeps dying

MV3 service workers get killed and restarted constantly, so session state can't live in memory. Access token, refresh token, and expiry persist to chrome.storage.local, and every authenticated call checks freshness first and silently refreshes before the request fires. Login also triggers an automatic bookmark import — zero clicks between the OAuth callback and a populated dashboard.

Problem 3

Author attribution has no single reliable selector

X renders author info differently depending on where in the tree you look — sometimes a labeled name block, sometimes a bare anchor tag. One selector alone silently dropped authors on a chunk of tweets. Fixed with a cascading fallback: labeled block → @-prefixed span scan → profile-link parsing.

Known limitation — not hidden

Categorization calls Groq once per tweet during bulk import. Past roughly 50 tweets in a single import, parallel requests get rate-limited and silently fall back to "Other." The fix — sequential calls with a short delay — was next on the list when the project paused.

02

Channel results

Channel Views Engagement Notable
Product Hunt directory 20 1 upvote · 0 comments Dead
X (18 posts, 3 weeks) ~790 ~11 likes Mostly own thread replying to itself
Substack (2 posts) 139 5 subscribers —
Reddit (2 posts) best 1,083 2 upvotes · 1 comment 2 unprompted beta-test DMs

Cold-directory launch (Product Hunt) underperformed community-native launch (Reddit) by a wide margin despite similar effort. Reddit delivered 54× more views than Product Hunt and the only unprompted beta-test requests — out of roughly 2,000 total views across all four channels.

03

The loop worked. The retention didn't.

The capture-and-categorize loop worked — bookmarks saved and auto-organized with zero manual effort. What was missing was a retention layer: a reason to open Knot on day 30, not just day 1. Cross-channel testing showed weak organic pull outside personal network. Rather than build a retention system on unvalidated demand, paused Knot and moved on.
